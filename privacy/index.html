Privacy policy

Last updated September 8, 2026

Loading_Out is a personal automation assistant. This page explains what data it accesses when connected to a TikTok account, and how that data is handled.

What data is accessed

When authorized, Loading_Out may access:

  • An access token and refresh token issued by TikTok, used to authenticate future requests
  • Basic account identifiers needed to address API requests (such as the TikTok Open ID)
  • The content (video or photo files, captions, and posting settings) that the owner explicitly provides to be uploaded or posted

What data is not accessed

Loading_Out does not read private messages, does not access other users' data, and does not use any TikTok data for advertising, profiling, or resale.

How data is stored

Access and refresh tokens are stored locally on the owner's own device, alongside the rest of the assistant's configuration. They are not transmitted to any third party other than TikTok's own API endpoints, which are required to perform the requested actions.

How data is used

Data obtained through the TikTok API is used solely to perform the actions the owner requests — for example, uploading a video or checking the status of a post. It is not shared, sold, or used for any purpose beyond fulfilling those requests.

Data retention and deletion

Tokens and related data are retained only as long as the assistant remains authorized. Revoking access from TikTok's connected-apps settings, or removing the local configuration, deletes this data.

Third parties

The only third-party service Loading_Out communicates with, in connection with this authorization, is TikTok's own API. No data is shared with any other external service or advertiser.

Changes to this policy

This policy may be updated as the project evolves. Material changes will be reflected on this page with an updated date.

Contact

Questions about this policy can be directed to the project owner directly.

This is a personal, single-owner project rather than a commercial service — this policy reflects that scope.
